<h2>📖 Introduction</h2>
<p>
<b>Mernoc Chat</b> is a high-performance, full-stack messaging platform engineered for seamless communication. Built with a focus on <b>scalability and user experience</b>, the application provides a robust infrastructure for modern conversations, ensuring speed, security, and a clutter-free interface.
</p>

---

<h2>✨ Features</h2>

<h3>✅ Core Backend Functionality (Current)</h3>
<ul>
  <li><b>Secure Authentication:</b> Passwordless login via Phone OTP (SMS-based) and Email OTP (Gmail-based).</li>
  <li><b>User Discovery:</b> Efficient system to browse and find users within the platform.</li>
  <li><b>Profile Management:</b> Fully customizable user profiles including bios and avatars.</li>
  <li><b>Advanced Messaging:</b> Support for sending, editing, and deleting messages.</li>
  <li><b>Status Tracking:</b> Real-time message delivery receipts and "Seen" indicators.</li>
</ul>

<h3>🚀 Upcoming Roadmap (Future)</h3>
<ul>
  <li><b>Real-Time Engine:</b> Low-latency bidirectional communication using Socket.io.</li>
  <li><b>Multimedia Sharing:</b> Seamless exchange of high-quality images, videos, and documents.</li>
  <li><b>Voice & Video:</b> High-fidelity calling features for personal and group connections.</li>
  <li><b>Security Suite:</b> Implementation of End-to-End Encryption (E2EE) for total privacy.</li>
  <li><b>Social Tools:</b> Group chats, status/stories, reactions, and typing indicators.</li>
</ul>

<h2>🛠️ Installation & Setup</h2>

<ol>
  <li>Clone the repository:
    <pre>https://github.com/prodip-shadow/Mernoc-Chat.git</pre>
  </li>
  <li>Install dependencies for both environments:
    <pre># For Backend
cd backend && npm install

# For Frontend
cd ../frontend && bun install</pre>
  </li>
  <li>Configure your <code>.env</code> file with the following variables:
    <ul>
      <li><code>MONGODB_URI</code>: Your MongoDB connection string</li>
      <li><code>JWT_SECRET</code>: A secure secret key for tokens</li>
      <li><code>OTP_API_KEY</code>: Credentials for SMS/Email OTP services</li>
    </ul>
  </li>
  <li>Start the development environment:
    <pre>bun start</pre>
  </li>
</ol>
